
# Movie Ticket Booking System

## Project Description
A console-based Movie Ticket Booking System developed using Core Java.

The application allows users to view movies, select showtimes, book tickets, manage bookings and calculate revenue.

## Features
- View available movies
- Book movie tickets
- Select showtimes
- Select seats
- View booking details
- Cancel bookings
- Add, remove and update movies
- Search movies by name or genre
- Sort movies by ticket price
- Generate revenue reports

## Technologies Used
- Java
- Object-Oriented Programming
- Java Collections Framework
- Exception Handling
- Data Structures and Algorithms

## Concepts Implemented
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Custom Exceptions
- ArrayList, HashMap and HashSet
- Bubble Sort

## How to Run

Compile:
javac -d out src/*.java

Run:
java -cp out MovieTicketBooking

Java Console-Based Application
